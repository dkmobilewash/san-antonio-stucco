targets yet. No action proposed for these; they should self-resolve.

## Proposals out of scope this run

- **`/stucco-painting` and `/stucco-repairs` ranking poorly (position 45.6
  and 46.8)** despite the homepage ranking well for the same queries
  ("stucco painting" pos 7, "stucco repair san antonio" pos 5–14). This looks
  like keyword cannibalization between the homepage and the dedicated
  service pages. Fixing it well needs a content/internal-linking strategy
  decision (e.g., de-emphasizing those terms on the homepage or building out
  the service pages further), which is a bigger, human-judgment call than a
  title tweak — flagging for a human to decide the site's cannibalization
  strategy rather than picking one unilaterally.
- **`/stucco-installation` and `/stucco-replacement`** both show 0% CTR at
  decent positions (pos 9 / 7.5), but their per-query breakdown in GSC is
  too thin and scattered (mostly 1–2 impressions per query, with a large
  "(other)" bucket GSC doesn't expose) to justify a confident, targeted
  rewrite this round. Their titles are already under the character limit and
  reasonably front-loaded. Recommend re-checking next run once more data
  accumulates.
- **New blog post**: no query cluster with real impressions (≥20) lacks an
  existing page or post that already covers it. The biggest raw opportunity,
  "stucco painting" (194 impressions), already has both a dedicated service
  page (`/stucco-painting`) and a blog post (`/blog/can-you-paint-stucco`) —
  the problem there is cannibalization/CTR, not missing content. No new post
  proposed this run.
- **Redirect-URL impressions** (`/eifs-synthetic-stucco/san-antonio`,
  `/stucco-installation/san-antonio`, `/commercial-stucco/san-antonio`, and
  similar `/service/location` combo URLs): these 301-redirect to the plain
  service page per `vercel.json`. No content exists at these URLs to edit;
  no action needed beyond letting Google's index catch up.
- **Signed Supabase image URLs**: `seo:lint` did not raise an image-expiry
  warning within its 180-day window this run, so no image migration is
  flagged this time, but the underlying signed-URL setup (mentioned in the
  skill's recurring notes) remains a standing human task to move to a public
  bucket eventually.
- **`/services` and homepage description over-length**, plus the ~25
  pre-existing blog title/description warnings not touched above: these are
  pre-existing lint warnings on pages this run didn't otherwise touch, so
  per the skill's rules they're not this run's to fix. Listed here for
  visibility; a future run touching those specific posts for another reason
  should shorten them at that time.
